# The Dawn of APRA

A historically inspired political/economic strategy game set in Peru, 1985–1992.

## Run locally

No build system is required.

1. Download this repository.
2. Open `index.html` in a modern browser.

For GitHub Pages, upload the files to a repository and enable Pages from the repository's settings.

## Project structure

- `index.html` — game shell
- `style.css` — interface
- `src/game.js` — game engine
- `src/data/events.js` — event cards and choices
- `LICENSE` — MIT license

## Design

The game uses original code and original UI. It is inspired by the event-card / political-crisis strategy genre, rather than copying another game's code or assets.

## Historical note

The simulation is an abstraction. Historical people, organizations, events, and policies are simplified for gameplay and should not be interpreted as a complete historical account.
